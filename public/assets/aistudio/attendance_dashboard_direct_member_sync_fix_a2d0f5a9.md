<project_context>
- **المشروع:** تطبيق ويب (`3fetyayouth.online`) مرتبط بـ `Cloudflare Database` (`threefetyayouth-api`).
- **الحقيقة التشخيصية الحاسمة (THE SMOKING GUN):**
  1. الحضور والأختام **ظاهرة بالفعل وبشكل سليم 100% للمخدومين داخل صفحاتهم الشخصية** (أي أن بيانات الحضور والأختام والتوقيت محفوظة وموجودة بالفعل داخل مصفوفة `members` و/أو سجل الماسح الضوئي!).
  2. ولكن في **`داشبورد سجل الحضور والغياب`**، لا تظهر أسماء هؤلاء الحاضرين!
- **السبب التقني الجذري الدقيق:**
  `داشبورد سجل الحضور والغياب` يعتمد في عرضه على مصفوفة منفصلة أو فلتر تاريخ صارم (`attendanceRecords.filter(r => r.date === selectedDate)`) لا يقرأ من الحضور والأختام المحفوظة داخل كائنات `members` نفسها، أو يفلتر بصيغة تاريخ لا تطابق صيغة التاريخ المحفوظة في أختام وحضور الأعضاء (`ISO Timestamp` vs `YYYY-MM-DD` vs `LocaleDateString`)!
- **الهدف النهائي القاطع (100% Permanent Fix):**
  جعل `داشبورد سجل الحضور والغياب` (سواء في **حضور اليوم الفعلي العالمي UTC** أو في **التقويم التفاعلي عبر السنين**) يستمد ويعرض قائمة الحاضرين مباشرة من **بيانات الحضور والأختام الموجودة في صفحات الأعضاء (`members`) مدمجة مع سجلات الماسح الضوئي والتحضير اليدوي**، بحيث يظهر **كل شخص أُخذ له حضور (يدوياً أو بالـ QR Scan) بنفس التوقيت الفعلي ونفس الترتيب الذي حضر به بنسبة 100%**!

### Task 1: بناء محرك استخراج الحضور الموحد من حسابات الأعضاء وسجل المسح (`Unified Member-Driven Attendance Extractor`)
- **المطلوب بالتفصيل في ملف `AttendanceDashboard.tsx` (أو القسم الخاص بداشبورد سجل الحضور والغياب داخل `Dashboard.tsx` / `App.tsx`):**
  1. **توحيد دالة استخراج التاريخ (`normalizeDateKey`):**
     - أنشئ دالة تحول أي تاريخ أو طابع زمني (سواء كان `timestamp` رقمي، أو `ISO string` مثل `2026-11-15T...`، أو تاريخ نصي `YYYY-MM-DD` أو `DD/MM/YYYY`) إلى مفتاح تاريخ قياسي موحد `YYYY-MM-DD`:
       ```javascript
       function toStandardDateKey(input) {
         if (!input) return '';
         if (typeof input === 'string' && /^\d{4}-\d{2}-\d{2}$/.test(input.trim())) {
           return input.trim();
         }
         const d = new Date(input);
         if (!isNaN(d.getTime())) {
           return d.toISOString().split('T')[0];
         }
         return String(input).split('T')[0].trim();
       }
       ```
  2. **الاستخراج المباشر من كائنات `members` + `attendanceRecords` + `scannerLogs`:**
     - بما أن الحضور والأختام ظاهرة في صفحات المخدومين، قم ببناء قائمة الحاضرين لأي يوم (`targetDateKey`) عبر فحص **جميع الأعضاء في `members`** إلى جانب سجلات الحضور العامة:
       - افحص لكل عضو (`member`) جميع الحقول التي تخزن حضوره وأختامه في صفحته الشخصية:
         `member.stamps`, `member.attendanceDates`, `member.attendanceHistory`, `member.attendance`, `member.presentDates`, `member.lastAttendance`, بالإضافة إلى السجلات الموجودة في `attendanceRecords` / `scannerLogs`!
       - إذا وُجد للعضو ختم أو سجل حضور يطابق `targetDateKey` (بتوقيت UTC أو التوقيت المحلي لليوم المختار)، **يُعتبر هذا العضو حاضراً رسمياً 100% في هذا اليوم ويُضاف فوراً إلى كشف الحضور!**
