# دفعة المهام (Update Open Graph & Meta Tags for Link Sharing)

<project_context>
- **المشروع:** تطبيق ويب (`3fetyayouth.online`).
- **المشكلة الحالية:** عند مشاركة رابط الموقع (على واتساب أو منصات أخرى)، تظهر معاينة الرابط بالعنوان القديم (مثل "نظام إدارة بيانات وافتقاد وحضور اجتماع الثلاثة فتية للشباب السوداني - كنيسة السيدة العذراء مريم بالزيتون").
- **الهدف:** استبدال النص الوصفي بالكامل في ميتات مشاركة الروابط ليصبح: **أسرة اجتماع الثلاثة فتية القديسين للشباب الجامعي و الخريجين**.
</project_context>

---

<tasks>
نفذ المهمة التالية بدقة تامة في ملف الهيكل الرئيسي (`index.html`) أو ملف الـ Meta Tags / Open Graph:

### Task 1: تحديث وسوم Open Graph و Meta Description لمعاينة الرابط
- **المطلوب بالتفصيل:**
  1. ابحث في ملف `index.html` (أو ملف الهيدر / الـ Layout الرئيسي) عن وسوم الـ Open Graph والـ Meta الخاصة بمشاركة الروابط، وتحديداً:
     - `<meta property="og:title" ... />`
     - `<meta property="og:description" ... />`
     - `<meta name="description" ... />`
     - وسوم Twitter Cards (`twitter:title`, `twitter:description`) إن وجدت.
  2. قم بتحديث ووصف النصوص القديمة بالكامل لتصبح حصرياً كالتالي:
     - العنوان والوصف (`og:title`, `og:description`, `description`): 
       **أسرة اجتماع الثلاثة فتية القديسين للشباب الجامعي و الخريجين**
  3. تأكد من تحديث عنوان الصفحة العام (`<title>`) أيضاً إن لزم الأمر ليطابق الاسم الجديد، وحفظ التعديلات.
</tasks>
